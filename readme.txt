Turn groups of near-duplicate simple products into one variable product, with review and one-click Undo.

== Description ==

Many stores start with one simple product per colour or size ("Tri-Rings Black", "Tri-Rings Blue"). Variant Collections scans your catalog, proposes the groups, and for each group you approve it builds one variable product. Your original products are hidden, never deleted, and Undo restores them.

* Review every proposed group before anything changes
* Variations reuse the originals' SKUs, prices, stock and images
* Non-destructive: originals are kept; Undo restores them
* Dismiss groups that are not variants

== Installation ==

1. Install and activate WooCommerce, then this plugin.
2. Go to Products > Variant collections.
